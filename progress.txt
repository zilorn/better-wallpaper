## 2026-07-01 Phase 2：CPU 资源预算与 LRU

- 新增 `ResourceCache`，使用规范资源路径与内容哈希作为热重载安全的缓存键
- CPU 缓存预算强制限制在 1～512 MiB，单资源大于预算时返回稳定错误，不尝试无界分配
- 插入时精确维护已用字节，按最近使用时间驱逐；时间相同时按路径和哈希确定性排序
- 缓存驱逐输出英语 debug 日志，不记录资源内容
- 新增预算校验、替换记账和 LRU 顺序测试；scene-format 共 35 项测试及严格 Clippy 通过
- 当时 Phase 2 剩余：模型 JSON 解析、GPU 资源预算与缓存

## 2026-07-01 Phase 2：GPU 资源预算与 LRU

- 在 `better-wallpaper-renderer` 新增通用 `GpuResourceCache<T>`，不把 GPU 对象反向耦合到格式 crate
- 显存缓存预算强制限制在 1 字节～2 GiB；单资源超限时返回稳定错误且不改变现有缓存
- 使用规范资源路径与内容哈希作为键，按访问顺序执行确定性 LRU 驱逐并精确记录显存字节数
- 缓存独占 GPU 句柄，驱逐、替换、移除和清空会立即触发句柄 `Drop`，避免账面释放而底层资源仍存活
- 驱逐使用英语 debug 日志，不记录资源内容
- renderer 6 项单元测试与严格 Clippy 通过
- Phase 2 剩余：模型 JSON 解析；当前缺少合法样本字段证据，不猜测私有格式语义

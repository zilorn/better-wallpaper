# 进度日志 - Scene 壁纸支持

## 2026-07-18 原生时间组件与内置实心图层

- Scene IR 保留文字内容、颜色以及受限的时钟/日期动态类型；不执行项目 JavaScript，仅识别 `Date` API 的安全原生模式。
- niri GPU 路径使用场景声明的 TTF/TTC 字体文件和真实字形度量渲染静态文字、24 小时时钟和中文星期日期；包内字体缺失时继续查找 Wallpaper Engine 资产字体，缺字再使用系统 CJK 字体回退。
- 修正场景坐标为左下原点，时间与日期不再因错误的 Y 轴映射落到画面下方；文字四边形按实际字体行高和宽度生成，不再拉伸到编辑器文本框尺寸。
- 字号会按场景画布高度与 1080p 设计视口的比例换算到场景坐标；3840×2160 场景不再把文字二次缩小，实际输出分辨率变化时仍保持一致的相对尺寸。
- Scene Sound IR 支持字符串或单元素数组资源、loop/once、音量与初始静音；基础背景音乐不再被统一判定为不兼容，高级随机/定时播放字段仍明确报告为 unsupported。
- niri 场景会安全提取包内背景音乐并复用 FFmpeg + Rodio 播放，首帧提交后启动，跟随全局静音、暂停、取消和热重载，循环结束时自动 seek 回开头；音频失败不会阻断画面。
- 严格识别 `registerAudioBuffers` 场景脚本模式但不执行 JavaScript；通过 PulseAudio/PipeWire 默认输出 monitor 捕获整个桌面声音，生成带平滑的 64 段对数频谱并驱动 GPU 柱状响应。
- 桌面 monitor 显式请求 20ms 录音分片并由服务端混为单声道；1024 样本窗以 512 样本步进约 93.75Hz 更新，预计算频段系数并加快攻防平滑，降低默认大缓冲造成的延迟和阶梯卡顿。
- 场景呈现按 Wayland compositor frame callback 节奏提交；Debug 模式每秒输出实际 FPS、平均/最大工作耗时、超预算帧、捕获字节数、频谱更新率与峰值，不再依赖被日志过滤器丢弃的逐帧 Trace。
- `models/util/solidlayer.json` 无需包内模型即可生成实心纹理；识别 `getSeconds() / 60` 模式后按系统秒数更新 X 方向进度。
- 真实场景 `2893997853` 的 headless 验证包含 1 条 24-bit/48kHz 双声道循环 FLAC、64 个频谱柱和 68 个可提交 draw；实际 FLAC 完整解码为 10,856,960 个交错采样。
- workspace 测试全部通过，workspace 全 target 严格 Clippy (`-D warnings`) 通过。

- TEXB0003/TEXB0004 FreeImage 解析不再读取首张图后提前返回，完整保留连续 PNG/JPEG mip 链
- PNG 解码按实际 RGB/RGBA/灰度通道规范化为 RGBA8，修复 RGB PNG 被错误写入 RGBA 缓冲区造成的通道错位
- 新增 JPEG mip 解码；真实 5760×2880 主纹理及其 5 级 mip 全部通过尺寸与上传数据校验
- 区分 TEXB0004 非视频 FreeImage 的真实头布局，真实 3157×3516 RGBA PNG 纹理及其 5 级 mip 可正确解析
- 场景 UV 改为按实际 GPU 上传尺寸计算，内嵌图片不会再因 TEX 头中的 power-of-two padding 尺寸被错误裁切
- GPU 保留作者 mip 并以 box filter 补齐到 1×1，支持时启用三线性采样，改善 4K/5.7K 场景缩放到 1080p 时的锯齿与闪烁；ES2 非 POT 限制下安全回退双线性
- 纹理超过 `GL_MAX_TEXTURE_SIZE` 时自动从作者 mip 链选择首个硬件可上传级别，例如 5760×2880 在 4096 上限设备改用 2880×1440，而不是整层渲染失败
- `scene-inspect` 可直接检查解包的 `scene.json` 和 `.tex`，支持文本摘要与 JSON 详情
- 新增 TEXB0003/TEXB0004 多 mip RGB PNG 与 padded 上传 UV 回归测试；workspace 全部测试及相关 crate 严格 Clippy 通过

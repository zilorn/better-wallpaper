目标是用可复现的格式证据和播放结果，逐步扩大 Better Wallpaper 对 Wallpaper
Engine 项目的支持范围。每项适配分别记录“可识别、可解析、可渲染、实机验证”状态；
L0–L3 元数据等级不等同于整个项目可播放，也不等同于 niri 与 Plasma 均已支持。

本文件是后续适配的执行路线图。[原场景计划](../plan.md)保留历史设计和进度，
当前行为以实现及分类技能为准。下列未勾选项是计划，不表示已经实现。
已交付工作与验证结果记录在对应工作包下，不承诺未经验证的完成日期。

### A2：体积纹理与 3D LUT

证据：本机 28 个 LUT 纹理设置 0x40 标志并带额外深度字段；当前二维上传契约拒绝这些资源。

- [ ] 核实 TEXI/mip 的深度、切片顺序、压缩布局，以及调色效果使用的坐标、颜色空间和插值方式。
- [ ] 引入有界体积纹理数据结构，校验宽×高×深×像素大小及整个 mip 链的内存预算。
- [ ] 根据实际 GL/GLES 能力选择原生 3D 纹理或二维切片实现，保持相同采样语义。
- [ ] 接入调色效果和参数绑定；仅成功解析 LUT 不授予效果播放能力。

设备缺少所需能力时可诊断且不会误绘制。涉及场景格式、共享计划和 GPU 效果路径。
